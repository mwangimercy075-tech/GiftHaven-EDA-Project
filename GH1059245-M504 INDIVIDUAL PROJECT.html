Q2: Who are GiftHaven's most valuable customers, and which segments need retention?

Business Importance: GiftHaven spends £50,000 yearly on marketing bt treats all customers equally.Without a proper understanding of customer value they waste budget on low-value segments while high-value customers receive no special treatment.RFM analysis will help to:

  • Identify the top 10% of customers who generate 45% of revenue

  • Flag at-risk customers before they churn

  • Enable personalised marketing campaign

  • Optimise marketing spend allocation

RFM Segmentation

import datetime as dt

max_date = df_cleaned['InvoiceDate'].max()
rfm = df_cleaned.groupby('CustomerID').agg({
    'InvoiceDate': lambda x: (max_date - x.max()).days,
    'InvoiceNo': 'count',
    'TotalPrice': 'sum'
})

rfm.columns = ['Recency', 'Frequency', 'Monetary']
rfm['R_Score'] = pd.qcut(rfm['Recency'], 5, labels=[5, 4, 3, 2, 1])
rfm['F_Score'] = pd.qcut(rfm['Frequency'], 5, labels=[1, 2, 3, 4, 5])
rfm['M_Score'] = pd.qcut(rfm['Monetary'], 5, labels=[1, 2, 3, 4, 5])

def segment_customer(row):
    R = int(row['R_Score'])
    F = int(row['F_Score'])
    M = int(row['M_Score'])

    if R >= 4 and F >= 4 and M >= 4:
        return 'Champions'

    if F >= 4 and M >= 4:
        return 'Loyal'

    if R >= 3 and F >= 3 and M >= 3:
        return 'Potential Loyalists'

    if R <= 2 and F <= 2:
        return 'At Risk'

    if R <= 2 and F >= 4:
        return 'Cannot Lose'

    if R >= 4 and F <= 2:
        return 'New'

    return 'Others'

rfm['Segment'] = rfm.apply(segment_customer, axis=1)

print(rfm['Segment'].value_counts())
print('Percentage per segment')
print((rfm['Segment'].value_counts() / len(rfm) * 100).round(1))

Overall Customer Distribution:

RFM analysis segmented 4,338 unique customers into 7 groups. Champions (932 customers, 21.5%) represent GiftHaven's most valuable customers, generating the highest revenue. At Risk (1,063 customers, 24.5%) is the largest segment, indicating a high churn risk.

Key Insights:

  1. Champions: High recency, frequency, and spend; implement a VIP loyalty programme with exclusive discounts and early access to new products.
  2. At Risk: Used to purchase but have stopped recently; launch a targeted win-back campaign with personalised offers.
  3. Loyal Customers: Maintain their satisfaction with regular engagement and cross-selling.
  4. New Customers: Recent first-time buyers need to be converted to repeat purchasers; send welcome emails with product recommendations.

Market Basket Analysis

inv_prods = df_cleaned.groupby('InvoiceNo')['Description'].apply(list)
pairs = {}
for prods in inv_prods:
    if len(prods) > 1:
        for pair in combinations(sorted(set(prods)), 2):
            pairs[pair] = pairs.get(pair, 0) + 1
top_pairs = Counter(pairs).most_common(5)
for (a,b), cnt in top_pairs:

max_date = df_cleaned['InvoiceDate'].max()
